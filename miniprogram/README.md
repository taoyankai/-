# 华中商贸配送中心 · 微信小程序端（原生页面）

本目录是**微信小程序端**工程，采用**原生页面**（wxml / wxss / js）实现，不再是 web-view 壳。

## 为什么不用 web-view

| 限制 | 说明 |
| --- | --- |
| 主体限制 | **个人主体小程序不支持 `web-view` 组件**（微信硬规定）。本项目当前主体为个人，因此 web-view 方案不可用 |
| 域名门槛 | 即便换成企业主体，web-view 加载的域名也必须是已配置的「业务域名」——要求 **ICP 备案 + HTTPS + 站点根目录上传校验文件** |
| 审核风险 | 纯 web-view 壳容易被判定为「仅网页封装、无实质内容」而拒审 |

## 两条请求通道（改一个开关切换）

```
useCloud = false  →  小程序 wx.request 直连后端
                     适合本地联调（开发者工具勾「不校验合法域名」即可）

useCloud = true   →  wx.cloud.callFunction('api') → 云函数 → HTTP → 现有 Spring Boot 后端
                     正式环境用。小程序端无需配置任何「服务器域名」，也不需要 ICP 备案
```

**云函数是免备案的关键**：云函数运行在腾讯云侧，出网请求不受小程序域名白名单约束，
所以后端只要有公网地址（IP 也可以）就能被访问，域名备案这一步可以完全省掉。

> 后端仍是你现有的 Java 服务，**一行都不用改**。云函数只做转发。

## 四、正式环境（云函数通道，免备案）

### 1. 开通云开发

开发者工具顶部「云开发」→ 开通 → 记下**环境 ID**。

### 2. 填环境 ID 并切通道

```js
// config.js
useCloud: true,
cloudEnvId: '你的环境ID',
```

### 3. 部署云函数

右键 `cloudfunctions/api` → **上传并部署：云端安装依赖**。

### 4. 配置云函数环境变量

云开发控制台 → 云函数 → `api` → 配置 → 环境变量：

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `BACKEND_BASE_URL` | `http://221.192.236.175` | 后端**根地址，不带 `/api`**（函数会自动补齐）。用 IP + HTTP 也可以 —— 云函数出网不受小程序「服务器域名」白名单约束，所以**免备案、免 HTTPS 证书** |

### 5. 验证

重新编译 → 登录 → 提交一单，云函数日志里应能看到转发记录。

## 五、上线前置条件与个人主体的注意事项

| 事项 | 说明 |
| --- | --- |
| 主体类型 | **建议换企业/组织主体**（配送中心自己的营业执照）。个人主体虽可用云函数，但存在下列限制 |
| 服务类目 | 个人主体开放类目有限，**没有电商 / 百货 / 食品 / 配送类目**。本项目不涉及支付（免费发放），建议按「工具 → 信息查询」或「工具 → 预约/报名」申报，并在备注中说明「仅采集配送信息，不涉及商品销售与支付」 |
| 小程序名称 | 含企业字号（如「华中商贸配送中心」）的名称，个人主体大概率过不了名称审核 |
| 微信支付 | 个人主体**无支付权限**。本项目免费发放，暂不需要；若将来涉及押金/收费则必须换主体 |
| 换主体的代价 | **换主体 = 换 AppID = 云开发环境需重建**，因此建议**先定主体再开发**。代码侧已把 AppID 与环境 ID 全部集中到 `project.config.json` / `config.js`，换起来只改两处 |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示「云函数调用失败」 | `cloudEnvId` 没填 / 云函数未部署。见第四节 |
| 云函数转发失败：请求后端超时 | 云函数的 `BACKEND_BASE_URL` 指向的地址公网不可达（本地调试时云函数也在腾讯云侧，**访问不到你的 localhost**；本地联调请用 `useCloud: false`） |
| 后端返回的不是 JSON | `BACKEND_BASE_URL` 末尾多写了 `/api`，或指向了前端页面地址 |
| 一直转圈 / 401 | 登录态失效。重新登录；确认后端 `/api/client/**` 可访问 |
| 打开后停在登录页 | 手机号不在名单内（1001）、姓名与名单不一致（1005）、或核验失败次数过多被临时锁定（1006），均属预期；错误码见开发文档 §4.3 |
| 提交提示「地址缺少楼栋/门牌」 | 招标要求送货上门到门牌，地址必须含数字门牌且含「室/栋/单元」等关键词 |
| 修改地址按钮不见了 | 已用过 1 次自助改址（`addrChangeCount = 1`），或订单已发货 —— 均属预期，需联系客服 |
