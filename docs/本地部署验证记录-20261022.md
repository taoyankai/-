## 本次发现和处理

### 浏览器同源请求被误判为跨域

只有不带 Origin 的接口请求通过时，浏览器仍可能失败。本次实际浏览器登录暴露此问题：Nginx 用 `$host` 转发，丢掉宿主机映射端口 18081，后端返回 `403 Invalid CORS request`。

修复 `deploy/nginx/nginx.conf` 中 5 个反代位置：Host 使用 `$http_host`，并增加 `X-Forwarded-Host $http_host`，保留原始主机与端口。Nginx 配置检查通过并已在验证容器重载。同源登录/退出、未授权跨域拒绝，以及后台/H5 实际浏览器登录均回归通过。没有放宽 CORS 白名单。

### 未接真实物流时的模拟发货

初始验证配置继承了 `LOGISTICS_VALIDATE_ON_SHIP=true`，真实通道未配置时正确阻止发货。因此仅将 `deploy/verify/.env` 改为 `false`，重建验证 API 与 Nginx 后继续模拟流程。正式模板保留 `true`。

本次只证明本地发货流程与状态规则可用，不证明真实运单可用或真实物流查询成功。
